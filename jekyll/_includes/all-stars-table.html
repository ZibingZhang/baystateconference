{%- comment -%} Renders one Bay State Conference All-Stars table (School/Name columns), or nothing at all if there are no entries — a school year with no winter boys program, for instance, has no "Boys Winter" table. An optional honorable_mentions list renders as a second, identically shaped table beneath it, filtered by the same town chips. Wrapped in collapsible-group.html for its own eye-icon show/hide, with a row of town filter chips above the table(s) when there's more than one town to filter by (reusing schedule-filter.html's chip markup/CSS for a plain look-alike — see rankings-summary-table.html for the same trick — but wired by assets/js/collapsible-group-filter.js instead, since each table here needs its own independent filter scoped to its own collapsible-group rather than one filter applied to every table on the page). Include collapsible-group.js and collapsible-group-filter.js once yourself wherever you call this, same reasoning as collapsible-group.html's own comment.
