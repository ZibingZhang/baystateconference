{%- comment -%} Renders a grid of cards (icon + name + link). Defaults to every sport in _data/sports.yaml linking to that sport's own page - pass `items` to render a different {title, icon, url} list instead, e.g. the home page's Schools/Sports/Schedules entry points, /schedules/'s By School/By Sport, or a school's schedule year page linking each sport it played that year to schools//schedule///. The grid is auto-fit (see .cards in _layout.scss), so the column count always matches however many cards there are (up to however many fit at 200px each) - a 2-card list fills its row instead of leaving a gap where a 3rd column would go. Pass `url_suffix` to append the same path onto every card's own url without needing a bespoke items array just to change where they point - e.g. site.data.sports already has {title, icon, url} entries for each sport's home page; `url_suffix="schedule/current-season/"` reuses that list to link each one's current-season schedule instead. Usage: {% include cards.html %} {% include cards.html items=page.home_cards %} {% include cards.html url_suffix="schedule/current-season/" %} {%- endcomment -%} {%- assign cards = include.items | default: site.data.sports -%}
