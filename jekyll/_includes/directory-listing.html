{%- comment -%} Renders a "Directory" link-list of the current page's immediate children, discovered from page.directory_nodes (precomputed by _plugins/page_tree_generator.rb from the page tree it builds) instead of a hand-maintained internal_links/links front matter array. Add a page under an existing folder and it shows up here automatically; no parent page needs editing. Mirrors link-list.html's markup directly (rather than building it an items array, which plain Liquid has no syntax to construct) so children get the same bordered-row styling as every other link list on the site. Each child's label follows the same precedence as breadcrumbs.html: the child's own `breadcrumb` front matter, then an acronym match on its URL segment (see _data/acronyms.yaml), then its `title`. `page.directory_nodes` is precomputed by _plugins/page_tree_generator.rb (one Ruby pass per build) instead of walking site.data.page_tree in Liquid on every render. A page whose children should list newest-first instead of the default ascending order (e.g. a folder of generated school-year pages) sets `default_sort: desc` in its own front matter; page_tree_generator.rb reads that flag when building the tree.
