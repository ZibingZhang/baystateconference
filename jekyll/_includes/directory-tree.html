{%- comment -%} Recursively renders a page tree (built by _plugins/page_tree_generator.rb) as nested
disclosures, expanded by default unless the folder's URL is listed in the site config's `sitemap_collapsed_paths`. A folder's own summary links to its page when it has one (e.g. "EMISCA" is both a page and a folder containing "Awards"). Usage: {% include directory-tree.html nodes=site.data.page_tree %} {%- endcomment -%}
    {%- for node in include.nodes -%} {%- capture node_label %}{% include url-label.html segment=node.segment %}{% endcapture -%} {%- assign node_label = node_label | strip -%} {%- if node.children.size > 0 -%}
  • {%- if node.url -%} {{ node_label }} {%- else -%} {{ node_label }} {%- endif -%} {%- include directory-tree.html nodes=node.children -%}
{%- else -%}
  • {{ node.title }}
    • {%- endif -%} {%- endfor -%}
