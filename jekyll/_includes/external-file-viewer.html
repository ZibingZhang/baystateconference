The file's path (relative to that root) comes in via the `url` query param, e.g. /resources/external-file/?url=organization%3Dmiaa%2F...&name=Constitution Some file types (anything other than a PDF, basically) won't render in the iframe at all - browsers just show a blank frame or try to download it - so "Open in new tab" is always shown front and center rather than as a fallback the visitor has to go hunting for. {%- endcomment -%}
