{%- comment -%} Renders a list of {title, url} pairs as a bordered row list, styled like the file-browser/directory tree but with no search bar — these lists are always short, so search would just be clutter. External links get an external-link icon and open in a new tab; internal links get the page icon used elsewhere for pages, so it's obvious at a glance whether a click leaves the site. No default heading — callers say what their own list actually is ("Resources", "Awards", ...) rather than everything being lumped under one word that doesn't always fit. Usage: {% include link-list.html items=page.links heading="Resources" %} {%- endcomment -%} {%- if include.items and include.items.size > 0 -%} {%- if include.heading -%}

{{ include.heading }}

{%- endif -%}

  • {%- if is_external -%} {%- else -%} {%- endif -%} {{ item.title }}
