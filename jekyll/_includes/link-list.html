{%- comment -%} Renders a list of {title, url} pairs as a bordered row list, styled like the file-browser/directory tree. External links get an external-link icon and open in a new tab; internal links get the page icon used elsewhere for pages, so it's obvious at a glance whether a click leaves the site. No default heading — callers say what their own list actually is ("Resources", "Awards", ...) rather than everything being lumped under one word that doesn't always fit. No search bar by default — these lists are usually short enough that search would just be clutter. Pass `searchable=true` for the rare list long enough to actually need it (e.g. 15 years of BSC All-Stars), which adds a search box and an A-Z/Z-A sort toggle, same as the file-browser. Usage: {% include link-list.html items=page.links heading="Resources" %} {% include link-list.html items=page.links heading="Directory" searchable=true %} {%- endcomment -%} {%- if include.items and include.items.size > 0 -%} {%- if include.heading -%}
