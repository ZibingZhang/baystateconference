{%- comment -%} Renders one rankings summary table for a Gender/Season combination (e.g. "Girls Fall"): one row per school year (or, for a source whose division gets its own meet page - MIAA Sectionals - one row per school year/division) showing that row's top 3 team finishers, the row's own label linking to the corresponding meet hub page. Shared by BSC (_plugins/bsc_rankings_summary_generator.rb, reading team_scores.csv directly) and MIAA Sectionals/States (_plugins/ranking_page_generator.rb, reading their rollup rankings CSVs) - both precompute the same {heading, years: [{year, division, url, entries}], divisions} shape onto page.groups. A row with fewer than 3 finishers (a thin early season) still gets 3 cells - the missing ones just render empty - so every row in the table stays the same width. When a group has more than one division (Sectionals' North/South/etc., States' Division 1/Division 2/State), a row of filter chips - reusing schedule-filter.html/-chip's pill markup and CSS for a plain look-alike, but wired by rankings-filter.js instead of schedule-filter.js since each table here needs its own independent filter rather than one filter applied to every table on the page - lets you narrow the table down to one division. A row with no division (BSC, or a States year that wasn't split) never matches a division filter and stays hidden once one's active, same as schedule-filter.js's exact-match semantics. Pairs with assets/js/rankings-filter.js - include that once yourself wherever you call this (not from in here), same as schedule-filter.html does for schedule-filter.js.
