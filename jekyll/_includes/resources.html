Resources

{%- comment -%} Renders a page's `resources` front matter (a list of {title, url} pairs) as a bordered row list, styled like the file-browser/directory tree but with no search bar — resource lists are always short, so search would just be clutter. External links get an external-link icon and open in a new tab; internal links get the page icon used elsewhere for pages, so it's obvious at a glance whether a click leaves the site. Usage: {% include resources.html items=page.resources %} {%- endcomment -%} {%- if include.items and include.items.size > 0 -%}
    {%- for item in include.items -%} {%- assign url_prefix = item.url | slice: 0, 4 | downcase -%} {%- assign is_external = false -%} {%- if url_prefix == "http" -%} {%- assign is_external = true -%} {%- endif -%}
  • {%- if is_external -%} {%- else -%} {%- endif -%} {{ item.title }}
    • {%- endfor -%}
{%- endif -%}
