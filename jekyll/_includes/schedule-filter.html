{%- comment -%} Renders a row of toggle chips that filter every .schedule-group on the page by one data-* attribute already present on each row (see schedule-group.html/school-schedule-group.html) - e.g. "school" reads each row's data-school, which may hold more than one pipe-separated value (a game's two teams), matched against whichever chip is active. Pairs with assets/js/schedule-filter.js - include that once yourself wherever you call this (not from in here), since a page can use this more than once (e.g. a sport's schedule page filters by both school and level) and every active filter is ANDed together against each row, not just whichever one was clicked most recently. A group whose rows are all hidden by the combined filters shows its .schedule-empty-row (see schedule-group.html) in their place, rather than disappearing. Only renders when there's more than one distinct value - filtering a single-value list down to itself is pointless. include.attr required - the data attribute rows are read from, e.g. "school" reads each row's data-school include.values required - array of strings, the filter options (an "All" chip is always added first) include.label optional - accessible group label, defaults to "Filter" Usage: {% include schedule-filter.html attr="school" values=page.schools label="Filter by school" %} {%- endcomment -%} {%- if include.values and include.values.size > 1 -%}
