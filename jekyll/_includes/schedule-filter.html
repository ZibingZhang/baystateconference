{%- comment -%} Renders a row of toggle chips that filter every .schedule-group on the page by one data-* attribute already present on each row (see schedule-group.html/school-schedule-group.html) - e.g. "school" reads each row's data-school, which may hold more than one pipe-separated value (a game's two teams), matched against whichever chip is active. Pairs with assets/js/schedule-filter.js. A group whose rows are all hidden by the active filter hides itself too, rather than showing an empty table.
