{%- comment -%} Renders one Gender group of a school's one-sport schedule (e.g. "Boys"): every resolved game involving this school in that sport/gender, sorted chronologically. Rows are pre-sorted/pre-decorated (reoriented to this school's point of view - "opponent", "home", W/L/T "result" - and given display-formatted "date"/"time" strings) by _plugins/school_schedule_page_generator.rb. Wrapped in .schedule-group and each row tagged data-level/data-gender so schedule-filter.html/schedule-filter.js can filter by level and/or gender (ANDed together), showing the trailing .schedule-empty-row in place of the real rows if none match.
