{%- comment -%} Renders a grid of sport cards (icon + name). Defaults to every sport in _data/sports.yaml linking to that sport's own page - pass `items` to render a different {title, icon, url} list instead, e.g. a school's schedule year page linking each sport it played that year to schools//schedule/// rather than the sport's own /sports// page. Usage: {% include sport-grid.html %} {% include sport-grid.html items=page.sport_cards %} {%- endcomment -%} {%- assign sports = include.items | default: site.data.sports -%}

{{ sport.title }}
