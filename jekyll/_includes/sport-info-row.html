{%- comment -%} Renders one for a single key/value pair from a sport's data - see sport-info-rows.html, which calls this once per top-level key. Value shapes: - a plain string: rendered as text, or as a link if it looks like a URL (any URL renders as its domain, except an instagram.com one, which renders as "@" - matching the Instagram rows rendered separately via instagram-rows.html) - a hash with `name` plus `url` or `google-maps`: one link row, with the key as the label and `name` as the link text (e.g. a venue) include.label the key, humanized for display (dashes/underscores -> spaces, each word capitalized) include.value the value to render {%- endcomment -%} {%- assign words = include.label | replace: '-', ' ' | replace: '_', ' ' | split: ' ' -%} {%- capture display_label %}{% for word in words %}{{ word | capitalize }} {% endfor %}{% endcapture -%} {%- assign display_label = display_label | strip -%} {%- assign value_json = include.value | jsonify -%} {%- if value_json contains '{' -%} {%- assign link_url = include.value.url | default: include.value['google-maps'] -%} {%- if include.value.name and link_url -%} {{ display_label }} {{ include.value.name }} {%- endif -%} {%- else -%} {%- assign text = include.value | strip -%} {%- if text != '' -%} {{ display_label }} {%- if text contains 'instagram.com' -%} {%- assign username = text | split: '/' | slice: 3 | first -%} @{{ username }} {%- elsif text contains '://' -%} {{ text | remove_first: 'https://' | remove_first: 'http://' | split: '/' | first }} {%- else -%} {{ text }} {%- endif -%} {%- endif -%} {%- endif -%}
