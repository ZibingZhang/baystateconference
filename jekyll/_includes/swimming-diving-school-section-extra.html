{%- comment -%} Swimming & diving's section_extra: historical win counts (BSC/sectional/ state championships) for the "Girls" or "Boys" section of a school page - computed from results data rather than a static schools.yaml value, so it can't be expressed as an ordinary sport.swimming-diving.sections fact. Rendered by sport-info-sections.html alongside that section's own facts (e.g. its Instagram handle - see schools.yaml's sport.swimming-diving.sections). Expects `include.school` (the schools.yaml record) and `include.section` ("Girls" or "Boys" - any other section name renders nothing, since wins data doesn't apply to it). The win years themselves (`school.swim_wins`) are precomputed by _plugins/swimming_diving_school_wins_generator.rb - this used to scan the BSC/sectional/state rankings CSVs with Liquid `where_exp` on every render; that generator does it once in Ruby instead. BSC wins are split by Season since, unlike the MIAA sectional/state results, the BSC has fielded separate Boys Fall and Boys Winter championships across its history (Girls has only ever raced in the fall). {%- endcomment -%} {%- if include.section == "Girls" or include.section == "Boys" -%} {%- assign sex = "F" -%} {%- if include.section == "Boys" -%} {%- assign sex = "M" -%} {%- endif -%} {%- assign wins = include.school.swim_wins[sex] -%} {%- if sex == "F" -%} {%- if wins.bsc.size > 0 -%} BSC Wins {{ wins.bsc | join: ', ' }} {%- endif -%} {%- else -%} {%- if wins.bsc_fall.size > 0 -%} BSC Wins (Fall) {{ wins.bsc_fall | join: ', ' }} {%- endif -%} {%- if wins.bsc_winter.size > 0 -%} BSC Wins (Winter) {{ wins.bsc_winter | join: ', ' }} {%- endif -%} {%- endif -%} {%- if wins.sectional.size > 0 -%} Sectional Wins {{ wins.sectional | join: ', ' }} {%- endif -%} {%- if wins.state.size > 0 -%} State Wins {{ wins.state | join: ', ' }} {%- endif -%} {%- endif -%}
