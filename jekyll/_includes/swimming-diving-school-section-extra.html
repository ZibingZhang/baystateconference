{%- comment -%} Swimming & diving's section_extra: historical win counts (BSC/sectional/ state championships) for the "Girls" or "Boys" section of a school page - computed from results data rather than a static schools.yaml value, so it can't be expressed as an ordinary sport.swimming-diving.sections fact. Rendered by sport-info-sections.html alongside that section's own facts (e.g. its Instagram handle - see schools.yaml's sport.swimming-diving.sections). Expects `include.school` (the schools.yaml record) and `include.section` ("Girls" or "Boys" - any other section name renders nothing, since wins data doesn't apply to it). BSC wins are split by Season since, unlike the MIAA sectional/state results, the BSC has fielded separate Boys Fall and Boys Winter championships across its history (Girls has only ever raced in the fall). {%- endcomment -%} {%- if include.section == "Girls" or include.section == "Boys" -%} {%- assign school = include.school -%} {%- assign sex = "F" -%} {%- if include.section == "Boys" -%} {%- assign sex = "M" -%} {%- endif -%} {%- comment -%} Matches sectionals/states results against the school's town, its formal name, and any further aliases (most schools have none, since `school-name` alone already covers " High School"). {%- endcomment -%} {%- assign school_names = "" | split: "" -%} {%- assign school_names = school_names | push: school.town -%} {%- assign school_names = school_names | push: school.school-name -%} {%- if school.aliases -%} {%- for alias in school.aliases -%} {%- assign school_names = school_names | push: alias -%} {%- endfor -%} {%- endif -%} {%- assign bsc = site.data.swimming-diving.bsc.rankings -%} {%- assign sectionals = site.data.swimming-diving.miaa.rankings.sectionals -%} {%- assign states = site.data.swimming-diving.miaa.rankings.states -%} {%- comment -%} Displayed as a single year rather than the full school-year range: fall results show the range's first year, winter results show its second year. {%- endcomment -%} {%- if sex == "F" -%} {%- assign bsc_wins = bsc | where_exp: 'row', 'row.Sex == "F" and row.Season == "fall" and row.Place == "1" and school_names contains row.School' -%} {%- assign bsc_years = "" | split: "" -%} {%- for row in bsc_wins -%} {%- assign school_year_parts = row['School Year'] | split: '-' -%} {%- assign bsc_years = bsc_years | push: school_year_parts[0] -%} {%- endfor -%} {%- assign bsc_years = bsc_years | uniq | sort | reverse -%} {%- if bsc_years.size > 0 -%} BSC Wins {{ bsc_years | join: ', ' }} {%- endif -%} {%- else -%} {%- assign bsc_fall_wins = bsc | where_exp: 'row', 'row.Sex == "M" and row.Season == "fall" and row.Place == "1" and school_names contains row.School' -%} {%- assign bsc_fall_years = "" | split: "" -%} {%- for row in bsc_fall_wins -%} {%- assign school_year_parts = row['School Year'] | split: '-' -%} {%- assign bsc_fall_years = bsc_fall_years | push: school_year_parts[0] -%} {%- endfor -%} {%- assign bsc_fall_years = bsc_fall_years | uniq | sort | reverse -%} {%- if bsc_fall_years.size > 0 -%} BSC Wins (Fall) {{ bsc_fall_years | join: ', ' }} {%- endif -%} {%- assign bsc_winter_wins = bsc | where_exp: 'row', 'row.Sex == "M" and row.Season == "winter" and row.Place == "1" and school_names contains row.School' -%} {%- assign bsc_winter_years = "" | split: "" -%} {%- for row in bsc_winter_wins -%} {%- assign school_year_parts = row['School Year'] | split: '-' -%} {%- assign bsc_winter_years = bsc_winter_years | push: school_year_parts[1] -%} {%- endfor -%} {%- assign bsc_winter_years = bsc_winter_years | uniq | sort | reverse -%} {%- if bsc_winter_years.size > 0 -%} BSC Wins (Winter) {{ bsc_winter_years | join: ', ' }} {%- endif -%} {%- endif -%} {%- assign sectional_wins = sectionals | where_exp: 'row', 'row.Sex == sex and row.Place == "1" and school_names contains row.School' -%} {%- assign sectional_years = "" | split: "" -%} {%- for row in sectional_wins -%} {%- assign school_year_parts = row['School Year'] | split: '-' -%} {%- if row.Season == 'fall' -%} {%- assign sectional_years = sectional_years | push: school_year_parts[0] -%} {%- else -%} {%- assign sectional_years = sectional_years | push: school_year_parts[1] -%} {%- endif -%} {%- endfor -%} {%- assign sectional_years = sectional_years | uniq | sort | reverse -%} {%- if sectional_years.size > 0 -%} Sectional Wins {{ sectional_years | join: ', ' }} {%- endif -%} {%- assign state_wins = states | where_exp: 'row', 'row.Sex == sex and row.Place == "1" and school_names contains row.School' -%} {%- assign state_years = "" | split: "" -%} {%- for row in state_wins -%} {%- assign school_year_parts = row['School Year'] | split: '-' -%} {%- if row.Season == 'fall' -%} {%- assign state_years = state_years | push: school_year_parts[0] -%} {%- else -%} {%- assign state_years = state_years | push: school_year_parts[1] -%} {%- endif -%} {%- endfor -%} {%- assign state_years = state_years | uniq | sort | reverse -%} {%- if state_years.size > 0 -%} State Wins {{ state_years | join: ', ' }} {%- endif -%} {%- endif -%}
