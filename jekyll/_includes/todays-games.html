{%- comment -%} Lists Bay State Conference games scheduled for today, across every sport, sorted by time, then Girls before Boys/Coed, then sport alphabetically, then Team 1/Team 2. "Today" means the day this site was built (site.time), not the visitor's local day, since this is a static site - see .github/workflows/jekyll.yaml's daily scheduled build (timed after arbiterlive's daily fetch) for how this stays fresh. By default only Varsity games are listed (the homepage's "Today's Varsity Games"); pass include.all_levels=true to list every level instead (used by /schedules/), which also adds a Level column and a "Filter by level" chip row. site.data.schedule.todays_games(_all) (already filtered/sorted/decorated) and the todays_sports(_all)/todays_schools(_all)/todays_levels_all filter-chip value lists come from _plugins/todays_games_generator.rb, since Liquid alone can't do the multi-key custom-order sort this list needs.
