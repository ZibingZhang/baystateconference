## What we're missing

Below is a running list of known gaps in the archive, based what's already on file against the expected pattern for each era of MIAA's divisional structure. If you have any of these, please get in touch.

### Full-year gaps (MIAA)

Years with nothing on file at all, sitting in the middle of otherwise-covered ranges:

- **2001-2002** — nothing at all
- **2005-2006** — nothing at all

### Fall, girls-only era (2000–2012)

| Year      | Missing                                                                           |
| --------- | --------------------------------------------------------------------------------- |
| 2002-2003 | Entire fall season absent (only a winter boys record exists that year)            |
| 2004-2005 | State Championship result — we have North & South Sectional, but no State results |

### Winter, boys/girls separate era (2006–2017, sectionals = Central/South, North, West or Western Mass)

| Year      | Missing                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| 2002-2003 | Missing everything except boys Division 1/2 State — no sectionals for boys, no girls results at all          |
| 2007-2008 | West Sectional missing for both boys and girls                                                               |
| 2012-2013 | Central/South, North, and West Sectionals all missing for both boys and girls (only have Division 1/2 State) |
| 2016-2017 | Boys Central/South and North Sectional missing (girls complete that year)                                    |

### Winter, Central/West-North-South era (2017–present)

| Year      | Missing                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------- |
| 2019-2020 | Central/West Sectional and Division 1/2 State missing for both boys and girls (only have North & South Sectional) |
| 2021-2022 | Central/West Sectional missing for both boys and girls                                                            |

### Bay State Conference meet results

| Season      | Missing years                                                                        |
| ----------- | ------------------------------------------------------------------------------------ |
| Fall        | 2010-2011, 2011-2012, 2012-2013, 2014-2015                                           |
| Fall (Boys) | 2021-2022, 2022-2023                                                                 |
| Winter      | No results on file before 2016-2017; then 2019-2020, 2023-2024, 2024-2025, 2025-2026 |
